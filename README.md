# README
Data analysis for publication *Diversification of the Corophiida amphipod silk-spinning systems* in Organisms, Diversity, and Evolution Journal: the special issue, 20th International Colloquium on Amphipoda.

# Data Analyses
Please use R_Analyses file (R script), character state files (csv files) and tree (tree_newick.txt) for analysis: ancestral state reconstruction, Pagel's discrete model of correlated evolution, and stochastic character mapping.
